# 你说我猜

/你说我猜 创建；主持人 开始，私聊 /你说我猜 取词 房间码；群内 线索 内容；其他人 猜 答案。猜中得1分可开新轮；主持人 揭晓；积分、状态、结束。12个生活词，真人主持文字玩法。

这是独立实现的Yukino文字插件，不兼容麦麦SDK。无需联网或模型。群内使用完整指令前缀，例如`/你说我猜 状态`。秘密词只有已加入玩家在私聊取词时可见。房间存储在独立data_dir，30天未操作后过期；新建房间不覆盖进行中的旧房间。结束需发起者或机器人主人，其他参数在控制台配置，部分仅新房间生效。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/你说我猜 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
