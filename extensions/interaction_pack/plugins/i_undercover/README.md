# 谁是卧底

/谁是卧底 创建；3—12人 加入；主持人 开始。每人私聊 /谁是卧底 取词 房间码；群中描述后 投票 对方QQ；主持人 结算。平票重投，卧底出局平民胜，剩2人卧底胜。状态、结束。8组原创简单词对，投票并非匿名。

这是独立实现的Yukino文字插件，不兼容麦麦SDK。无需联网或模型。群内使用完整指令前缀，例如`/谁是卧底 状态`。秘密词只有已加入玩家在私聊取词时可见。房间存储在独立data_dir，30天未操作后过期；新建房间不覆盖进行中的旧房间。结束需发起者或机器人主人，其他参数在控制台配置，部分仅新房间生效。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/谁是卧底 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
