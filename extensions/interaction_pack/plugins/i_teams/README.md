# 队长蛇形选队

/选队 创建；4—12人 加入；发起者 选队长 QQ1 QQ2。队长轮流 选 待选QQ，顺序A-B-B-A循环。全部选完结束；状态、结束。报名后无法中途退场，请结束重建。

这是独立实现的Yukino文字插件，不兼容麦麦SDK。无需联网或模型。群内使用完整指令前缀，例如`/选队 状态`。秘密词只有已加入玩家在私聊取词时可见。房间存储在独立data_dir，30天未操作后过期；新建房间不覆盖进行中的旧房间。结束需发起者或机器人主人，其他参数在控制台配置，部分仅新房间生效。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/选队 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
