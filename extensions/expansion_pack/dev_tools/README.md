# Yukino 开发与数据工具扩展组

21 个原创独立插件，每项具有独立 ID、命令、配置 schema、worker 入口和安装包。共享 `dev_engine.py` 仅复用算法和输入边界，不额外计入插件数量。适配 Yukino Core 0.4.0 普通 `handle(text, context) -> str | None` 协议。

所有工具在本机计算，不访问网络、调用模型、读取聊天历史或保存用户输入。每项仅匹配自己声明的完整命令。错误以普通文字返回，不影响其他插件；输出超限明确注明截断。

| --- | --- | --- |

## 输入边界和解释

- 所有命令总长最多 24000 字符，单次回复默认最多 6000 字符，面板可设 1000～12000。
- 正则最多 300 字符模式和 4000 字符文本。为支持模式内的竖线，可以发送 `/正则测试 {"pattern":"cat|dog","text":"cat dog"}`；简写以第一个 `|` 分隔。正则使用固定 Python 子进程，默认 500 毫秒超时，超时会停止子进程，不使用 shell，不执行用户代码。
- 精确计算使用受限 AST 解析，仅支持数字与算术操作；不使用 `eval`，禁止函数、属性、变量和容器表达式。Decimal 受有效位数约束；Fraction 模式返回精确有理数，仍有大小上限。
- 矩阵最多 6×6，使用 Fraction；JSON 小数直接解析为 Decimal 后转有理数，避免先经过二进制浮点。统计采用中心化偏移和动态 Decimal 工作精度，保留大数偏移下的小幅差异，四分位是 `(n−1)p` 的线性插值。二次方程使用稳定 q 求根法，避免大系数使小根被消减为零。
- Cron 为标准五字段，只说明或计算，不安装定时任务；最多向前扫描 1096 天。按 Vixie 语义，日／星期任一字段以 `*` 开头（包括 `*/步长`）时采用 AND，否则采用 OR；星期 0/7 表示周日。支持数字、通配、列表、区间和步长，不支持秒字段或 L/W/#。
- 时间戳自动判别存在歧义时请显式使用 `s:` 或 `ms:`。纯数值绝对值 ≥1e11 视为毫秒；无时区 ISO 使用面板时区偏移，始终另外显示 UTC。
- MIME 来自运行时 Python 的扩展名表，不能代替文件内容检测。IP 信息来自标准库离线分类，不包含在线信誉、归属地或连接测试。
- 链接清理只移除已知跟踪参数，未访问 URL；清理后的链接可能受原站签名参数约束，应核对结果。

## 配置与使用

每个插件的 `plugin.json` 声明可编辑参数，个别插件另有缩进、表头、分隔符、显示精度、时区、输出数量、正则匹配数量等设置。没有需要服务器令牌的功能，也无需安装第三方依赖。

各插件的 `README.md` 提供完整语法和限制。`catalog.json` 包含每插件的 ID、名称、命令、有效烟测命令、应出现的回复片段及错误烟测命令，可供内核隔离验收使用。

## 打包约定

每个插件 ZIP 的根目录包含该插件的 `plugin.json`、`worker.py`、`README.md`，以及本组 `dev_engine.py` 的副本，命名为 `_engine.py`。由扩展包总构建器统一加入项目许可证。开发源码中的 worker 能回退加载组根目录的 `dev_engine.py`；独立安装包不依赖这个回退路径。

## 测试

运行：

```powershell
python -X utf8 -m unittest discover -s extensions/expansion_pack/dev_tools/tests -v
```

Windows 已通过 98 项测试：每项插件的有效输入、错误输入、普通消息不触发，以及独立 helper 加载、正则超时终止、Unicode、Cron 通配步长边界、SemVer 官方优先级链、精确分数、矩阵、概率边界、大偏移统计与稳定二次求根。服务器上的安装器/worker 测试由总扩展包验收记录单独确认。
