# 生活与协作扩展：21个独立插件

面向 Yukino Core 0.4.0 普通 worker 协议。所有代码为独立实现，不加载麦麦 SDK。各独立包内嵌共享实现 `_engine.py`，仅分发当前 `KIND` 的命令；每插件 `data_dir` 和 SQLite 各自独立。

## 隔离和权限

私人资料按 `session_id + user_id` 隔离。AA账本、活动报名、轮值、排队、议程只在 `g:` 群会话使用并共享；群知识页共享阅读。管理动作检查记录创建者与宿主 `owner_ids`，不采信聊天昵称或用户输入的“管理员”称谓。群成员只能加入或退出自己的报名／队列；支出由账本创建者或主人维护。

## 持久化和限制

只写宿主分配的 `data_dir/life.sqlite3`；每次命令一个 SQLite 事务。错误不提交部分修改。归档使用 active=0 保留内容。每用户/群每插件最多200条活跃记录、累计2000条；单条知识页最多50版、1500字/版；库存和AA单据各最多1000条流水；队列、报名和议题各最多100项。达到限额时拒绝新增，不静默截断历史。

番茄钟/工时开始时间可跨进程重启恢复。番茄钟无后台提醒，工时不设目标分钟，两者分别存储。纪念日和复习卡只提供查询；不承诺主动发送。记账与AA只计算记录，不连接支付服务，不作投资建议。

间隔复习使用明确的固定阶梯1、3、7、14、30、60天，自评0～2重置为1天，3～5提升一级；不是SM-2或AI评估。轮值严格循环，不声称随机公平抽签。决策表依据输入权重和0～10分计算加权平均，不替用户决定。

## 开发和测试

`python -X utf8 -m unittest discover -s extensions/expansion_pack/life_tools/tests -v`

`catalog.json` 提供21项真实创建/计算验收命令，不以帮助文字代替功能实测。共享项目验收须用 `g:` 会话。

## 面板参数

每个插件都提供实际生效的 `max_active_records`（整数10～200，默认200），限制当前用户／会话的活跃条目；群共享项目限制当前群。降低限制不会删除已有记录；归档后可释放活跃名额。累计2000条上限独立于此参数。
