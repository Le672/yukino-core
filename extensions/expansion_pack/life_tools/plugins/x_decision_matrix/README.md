# 加权决策表

多指标权重、选项评分和加权排名。

## 命令

/决策表 创建 名称|指标A:3|指标B:2；评分 编号 选项|8|9；结果 编号；权重 编号 指标A:1|指标B:1；移除 编号 选项；归档 编号

发送 `/决策表 帮助` 查看命令。编号来自创建成功回执，示例中的编号须换为自己的实际编号。

## 存储与边界

仅在内核分配的 `data_dir/life.sqlite3` 持久化；默认按会话与用户隔离。活跃记录最多200条，累计记录最多2000条；归档保留历史，不物理删除。输入和各项内部明细均有上限，失败事务回滚。

即使知道编号也不能读取或修改其他用户／会话的条目。

离线工作，无模型、网络或QQ发送权限。计时、到期、纪念日只在查询时计算，不会主动提醒或定时推送。

## 验收示例

`/决策表 创建 选设备|性能:3|续航:2`

预期含：决策表已创建。

## 面板参数

`max_active_records`：每用户／会话的活跃记录上限，默认200，可设10～200。群共享项目按当前群计数。调整后立即作用于新增记录；降到已有数量以下不会删记录，只暂停新增。归档释放活跃名额，累计2000条的历史保护上限保持不变。
