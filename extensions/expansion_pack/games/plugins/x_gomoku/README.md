# 九路五子棋

插件 ID：`x_gomoku` · 版本：1.0.0 · MIT

## 操作

/五子棋 开始；另一人 加入；/五子棋 行 列（1—9），固定9×9自由规则，连5及以上获胜，无禁手；状态、认输、结束。

开始示例：`/五子棋 开始`。发送 `/五子棋 帮助` 随时查看具体规则。

## 面板配置

本游戏采用固定棋盘/固定规则，未提供无效的装饰参数。

## 数据与边界

双人对局仅在同一群聊中共享；创建者占玩家1座位，另一人发送 加入 成为玩家2。只有落子方可行动，旁观者不可代走、结束或重开进行中的桌。井字棋另有“开始 人机”，支持私聊；私聊不创建等待别人加入的空桌。

进度保存在宿主分配的 `data_dir/games.sqlite3`，每一步在 SQLite 事务中校验并写入，非法输入不会消耗回合。worker 退出、进程池回收或内核重启后可继续。短期对局保留到最后操作后31天，每个插件最多保存5000份对局，超过时清理最久未操作的记录；不修改聊天历史或其他插件数据。没有联网、模型调用、主动QQ消息、金钱下注或第三方素材。

本插件为 Yukino 独立实现，需要使用随包提供的 `_engine.py` 与 `helper_*.py`。规则与商业游戏产品可能不同，以以上说明为准。
