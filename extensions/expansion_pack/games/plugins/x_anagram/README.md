# 乱序猜词

插件 ID：`x_anagram` · 版本：1.0.0 · MIT

## 操作

/乱序猜词 开始；/乱序猜词 猜 apple；状态；投降。将同一英文词的全部字母打乱，猜中完整单词获胜；重复输入不扣机会，错词消耗一次机会。可在面板设置机会数和是否显示原创中文线索。

开始示例：`/乱序猜词 开始`。发送 `/乱序猜词 帮助` 随时查看具体规则。

## 面板配置

- `max_mistakes`：允许猜错次数，默认 5，范围 2—10。新局采用修改后的参数，当前局继续沿用开局参数。
- `show_hint`：显示原创中文线索，默认 True，范围 None—None。新局采用修改后的参数，当前局继续沿用开局参数。

## 数据与边界

每个会话中的每位用户拥有独立对局，别人不能读取、操作或结束你的游戏。

进度保存在宿主分配的 `data_dir/games.sqlite3`，每一步在 SQLite 事务中校验并写入，非法输入不会消耗回合。worker 退出、进程池回收或内核重启后可继续。短期对局保留到最后操作后31天，每个插件最多保存5000份对局，超过时清理最久未操作的记录；不修改聊天历史或其他插件数据。没有联网、模型调用、主动QQ消息、金钱下注或第三方素材。

本插件为 Yukino 独立实现，需要使用随包提供的 `_engine.py` 与 `helper_*.py`。规则与商业游戏产品可能不同，以以上说明为准。
