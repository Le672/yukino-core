# 吊小人猜字母

插件 ID：`x_hangman` · 版本：1.0.0 · MIT

## 操作

/吊小人 开始；/吊小人 猜 a（单字母）或 /吊小人 猜 apple（完整英文词）；状态；投降。错误字母和错误整词各消耗一次机会，重复输入不消耗。词库与中文线索原创整理。

开始示例：`/吊小人 开始`。发送 `/吊小人 帮助` 随时查看具体规则。

## 面板配置

- `max_mistakes`：允许猜错次数，默认 8，范围 4—12。新局采用修改后的参数，当前局继续沿用开局参数。
- `show_hint`：显示原创中文线索，默认 True，范围 None—None。新局采用修改后的参数，当前局继续沿用开局参数。

## 数据与边界

每个会话中的每位用户拥有独立对局，别人不能读取、操作或结束你的游戏。

进度保存在宿主分配的 `data_dir/games.sqlite3`，每一步在 SQLite 事务中校验并写入，非法输入不会消耗回合。worker 退出、进程池回收或内核重启后可继续。短期对局保留到最后操作后31天，每个插件最多保存5000份对局，超过时清理最久未操作的记录；不修改聊天历史或其他插件数据。没有联网、模型调用、主动QQ消息、金钱下注或第三方素材。

本插件为 Yukino 独立实现，需要使用随包提供的 `_engine.py` 与 `helper_*.py`。规则与商业游戏产品可能不同，以以上说明为准。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/吊小人 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
