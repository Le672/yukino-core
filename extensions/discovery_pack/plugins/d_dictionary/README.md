# 英语词典与真人发音

`/查词 hello`、`/英语词典 computer`。返回音标、英文释义与例句，并发送有源的发音音频。无词条/无发音会如实说明；不是中英翻译或语音合成。查询词会发送到Free Dictionary API。

0.1.1：优先验证词典给出的发音媒体；媒体站不可用时，按同一发音条目明确引用的Wikimedia Commons页面，查询官方API返回的原始音频，不猜地址或合成发音。回复包含音频作者、独立的音频许可及来源页面；原始OGG音频也可作为真实音频文件发送。若官方来源也不可用，仍返回释义并明确提示发音不可用。

查询阶段最多请求词条、一个媒体端点及一个Commons元信息端点，共用设置中的网络预算（最多20秒）；随后由内核按现有媒体下载限制获取原音频。只访问公开HTTPS可信域名，不携带QQ身份、聊天记录或凭据。

设置用于后续调用；不会添加后台推送或额外模型调用。完整来源、许可和数据边界见随包NOTICE。
