# 媒体与发现插件包

Core 0.11.0+，七个独立ZIP，均可在插件管理启停。VPS安装后总计145项功能（含17原生、128外部，外部中有2个私人集成）；公开全套为143项，不含私人漫画/视频集成。

## 图片动效工坊

引用一张机器人已经收到的图片发送 `/摸头`、`/转圈`、`/像素化`、`/图片灰度`、`/图片镜像`；同条消息附图也可以。GIF可用 `/动图倒放`、`/动图加速 2`。`/图片工坊` 查看帮助。没有引用原文时请重新附图；不跨会话查历史，不查询QQ头像。

## 中文文字表情画板

`/举牌 今天不想上班`、`/记仇 他又抢走了最后一块蛋糕`、`/摸鱼牌 今日摸鱼指标已完成`。直接返回原创PNG图片，内容控制在160字以内，换行较多时需缩短。

## 本地二维码

`/二维码 https://example.com` 或 `/二维码 你好，世界`。输入最多700 UTF-8字节，不上传、不请求二维码中的网址，不提供解码。二维码采用标准四模块静区、无Logo遮挡。

## Epic限时喜加一

`/喜加一` 或 `/Epic免费`。默认CN商店，最多3个当前/即将免费商品，附封面与带UTC偏移的开始截止时间。地区、数量、缓存、联网和超时可在面板修改。只查询，不自动领取或登录账号。

## GitHub项目雷达

`/找项目 qq bot`、`/项目 Le672/yukino-core`。正常发GitHub仓库链接会自动预览，不用@。搜索词会发给GitHub公开API；不发QQ号、昵称、聊天历史或凭据。没有token，匿名API可能限流；不下载执行项目。

## 英语词典与真人发音

`/查词 hello`、`/英语词典 computer`。返回音标、英文释义与例句，并发送有源的发音音频。无词条/无发音会如实说明；不是中英翻译或语音合成。查询词会发送到Free Dictionary API。

## 城市空气质量与趋势

`/空气质量 上海`、`/空气质量 Beijing`、`/空气质量 31.23,121.47`。返回模型数据时间、PM2.5/PM10、AQI（美标）等和趋势图。地点由你指定，不查IP或定位。中文常见城市有英文检索别名；同名地点需核对回复地区。

## 来源与兼容

这些是Yukino接口的适配实现，不能将AstrBot或麦麦原包直接导入。来源和许可证见[SOURCES.md](SOURCES.md)。生成图片/动图/二维码在本地完成；查询功能访问对应公开来源，支持面板关闭联网、缓存和超时。接口失败时不编造结果。

图像工坊仅在明确调用时获取图像，不监听所有图片做特效；已有自动偷表情仍由原插件负责。GitHub链接预览采用已有自动链接机制，无需手动指令。
