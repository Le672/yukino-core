# Yukino 社区功能包 1.0.0

面向 Yukino Core 0.3.1+ 的可选 Python 插件。根据 QQ Agent 插件市场的功能需求独立实现；没有复制其无明确许可的 JavaScript，也不是运行 QQ Agent 插件的兼容层。

包含签到金币、指令好感互动、吃什么、跑团骰子、外号簿、天气、Steam 查价、热榜、网易云歌曲检索、Minecraft 状态和 B 站查询。功能均由明确指令触发；不增加逐条消息的模型请求。联网查询可能受源站网络与限流影响，错误会直接提示。

构建独立 ZIP：

```sh
python extensions/community_pack/build_pack.py --output ./dist/community-pack-1.0.0
```

在控制台「插件管理 → 从本地 ZIP 安装插件」逐个导入对应 ZIP，然后配置和启用。安装默认停用；联网插件建议将「执行超时」设为 18 秒，本地插件设为 5 秒（每包也提供 recommended_settings.json）。统一源码 ZIP 供开发使用，不能直接当单个插件导入。

签到、好感与外号数据保存在实例 `plugins/state/<插件ID>`，升级或重新安装同 ID 插件仍能继续使用；备份实例时一起保留该目录。它们不访问核心聊天数据库。金币是娱乐积分，没有充值、提现或真实支付。

功能边界：外号簿用于登记与查询，不自动修改模型身份或权限；好感仅按互动指令积累；本版不包含定时推送、图形卡片、语音播放、自动发布空间、RCON 或电脑遥控。每个插件的准确用法与参数见其 README。

所有插件依赖 Python 标准库，无需额外安装第三方依赖或填入 API 密钥。公开接口可能要求地区可达或调整限制。不要在插件普通参数中填写密码、Cookie 或 API Key。

功能参考与作者信息见 SOURCES.md。Yukino 新实现使用本包 MIT 许可；该许可不覆盖第三方服务的数据或商标。
