# TRPG骰子与CoC7检定

版本 1.0.0。功能参考 [QQ Agent 插件市场](https://kondius.cn/qq-agent/plugin-market/)，使用 Python 标准库独立实现，没有复制上游 JavaScript，不兼容其全部功能或原插件包。

指令：`/r 2d6+3`、`/ra 60 侦查`、`/coc [1-5]`、`/先攻 雪乃:2 小明:-1`。

骰式严格限定为单组 `nDm±k`，骰数最多100、面数最多100万、修正绝对值最多100万；不执行代码，不支持多个骰组。`/r` 与骰式间必须有空格。

`/ra` 使用明确的 CoC7 默认 d100 判定：1大成功，技能<50时96—100大失败，技能>=50时100大失败；极难/困难成功阈值分别为技能的1/5、1/2并向下取整；其余按技能值成功或失败。技能值只支持0—100，不含奖励骰/惩罚骰，也不自动套用房规。

`/coc` 仅生成基础随机属性：STR/CON/DEX/APP/POW 为3d6×5，SIZ/INT/EDU为(2d6+6)×5，LUCK独立3d6×5；未处理年龄、职业、衍生属性或技能，不是完整人物卡。

先攻为每人1d20加指定修正（-100—100），最多12人，同分保持输入顺序，不处理更复杂规则。所有随机使用系统随机源；测试可注入种子随机源但正式配置不接受用户种子。无网络、无文件写入。

安装后在 Yukino 插件管理中启用；此为主动指令型插件，群聊命中这些指令时可无需 @。内核应提供 `session_id`、`user_id`、`settings`，持久化插件还必须提供绝对路径 `data_dir`。独立状态不会写到源码目录。
