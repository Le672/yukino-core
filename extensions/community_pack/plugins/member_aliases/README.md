# 会话成员外号

版本 1.0.0。功能参考 [QQ Agent 插件市场](https://kondius.cn/qq-agent/plugin-market/)，使用 Python 标准库独立实现，没有复制上游 JavaScript，不兼容其全部功能或原插件包。

指令：`/外号 设置 小可爱`、`/外号 查 [QQ号]`、`/外号 清除`。

普通用户的设置和清除始终作用于自己的内核用户ID。主人管理：`/外号 管理 QQ号 设置 外号`、`/外号 管理 QQ号 清除`，权限只来自内核 `owner_ids`。按 `session_id` 隔离；查询任何已知QQ号的本会话显示外号是公开操作。

外号只用于此插件的展示查询，不自动改写模型提示词、群成员名片、NapCat账号或其他授权名单。将外号设为“主人”等文字不会获得权限。为避免消息片段歧义，拒绝控制字符、方括号和尖括号。

数据为内核独立数据目录的 `aliases.sqlite3`。

安装后在 Yukino 插件管理中启用；此为主动指令型插件，群聊命中这些指令时可无需 @。内核应提供 `session_id`、`user_id`、`settings`，持久化插件还必须提供绝对路径 `data_dir`。独立状态不会写到源码目录。
