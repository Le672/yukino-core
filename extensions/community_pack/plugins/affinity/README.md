# 指令互动与好感

版本 1.0.0。功能参考 [QQ Agent 插件市场](https://kondius.cn/qq-agent/plugin-market/)，使用 Python 标准库独立实现，没有复制上游 JavaScript，不兼容其全部功能或原插件包。

指令：`/好感`、`/互动 [打招呼|夸夸|击掌]`、`/好感榜`。

只在明确调用 `/互动` 时加分，不会自动读取、分析或计分普通聊天消息。每会话、每用户独立；UTC+8 日期重置每日可获积分，冷却按实际经过秒数检查。最后一次加分时间跨重启保存。达到日上限或总上限不再加分；剩余额度不足时仅发放剩余额度。

`owner_max` 默认关闭，开启后只匹配内核提供的 `owner_ids`，普通用户无法自行声明主人；满级特权不消耗日额度。好感榜展示实际已累积记录，主人特权需首次互动后形成记录。

数据为内核独立数据目录的 `affinity.sqlite3`。

安装后在 Yukino 插件管理中启用；此为主动指令型插件，群聊命中这些指令时可无需 @。内核应提供 `session_id`、`user_id`、`settings`，持久化插件还必须提供绝对路径 `data_dir`。独立状态不会写到源码目录。
