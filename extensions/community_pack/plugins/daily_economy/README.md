# 每日签到与娱乐积分

版本 1.0.0。功能参考 [QQ Agent 插件市场](https://kondius.cn/qq-agent/plugin-market/)，使用 Python 标准库独立实现，没有复制上游 JavaScript，不兼容其全部功能或原插件包。

指令：`/签到`、`/余额`、`/金币榜`、`/转账 QQ号 金额`、`/流水`、`/商店`、`/购买 商品ID [数量]`、`/背包`、`/经济帮助`。

金币为纯娱乐积分，无真实货币、充值、提现或赌博功能。按 `session_id` 隔离，每日以 UTC+8 上海日期划分。连续签到第2—7天每次增加 `streak_bonus`，第8天起额外奖励封顶；断签后重置。余额、单笔转账、购买数量及背包数量均有上限。转账只接受真实 QQ 数字ID和严格正整数。

商品 JSON 为最多20个 `{"id":"flower","name":"小花","price":30}`；ID唯一、价格正整数。库存为虚拟纪念物品，不会兑换外部物品。

状态在内核分配的数据目录 `economy.sqlite3`；事务内原子记账，签到重复调用不重复发放。备份该数据库须停止插件或使用 SQLite 在线备份接口；不要直接复制正在写入的数据库。

安装后在 Yukino 插件管理中启用；此为主动指令型插件，群聊命中这些指令时可无需 @。内核应提供 `session_id`、`user_id`、`settings`，持久化插件还必须提供绝对路径 `data_dir`。独立状态不会写到源码目录。
