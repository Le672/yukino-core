# 歌曲搜索 1.0.0

命令：`/搜歌 晴天`。使用网易云 music.163.com 的公开搜索接口返回歌曲 ID、歌手和官方歌曲页面。不获取音频、不生成直链、不绕过会员、登录或付费权限；无法查询时明确说明原站不可用。

独立重写的 Yukino Core 进程插件，只使用 Python 标准库；没有复制市场源代码或数据库。插件入口为 `handle(text, context)`，可变参数来自 `context.settings`。

请在插件管理把通用“执行超时（秒）”设置为 **18 秒**。内核通用默认值2秒不足以完成最多3次顺序网络查询。单次命令网络时间预算14秒；每次 HTTP 请求最多5秒，响应上限2MiB，固定 HTTPS 来源且禁止跳转，不自动重试；失败也缓存30秒，成功缓存30～300秒，缓存只在内存中、最多64个查询且响应原始字节总预算2MiB，不写本地文件。返回失败说明后终止，绝不交给模型虚构结果。

不需要API密钥。第三方公开接口无可用性保证，服务限流或格式变化会报错。数据与媒体权利归原站权利人，公开接口的访问不代表获得重新分发其数据的许可。

来源与接口依据：
- https://music.163.com/
