# Yukino 麦麦功能扩展包 1.1.0

本包1.1.0需要 Yukino Core 0.7.0+，支持统一结果卡与实际媒体/文件交付。逐项说明见 `docs/PLUGIN_OUTPUT_MATRIX.md`。

本包根据麦麦官方插件中心的功能需求独立实现，为 Yukino Core 0.4.0 增加 15 个可选 Python worker。群管与管理员、持久化提醒、关键词回复是另外 3 个需要宿主权限的原生扩展，随 0.4.0 核心提供，在插件管理中启停和配置。

本包不是 MaiBot SDK 兼容层，不直接加载麦麦的 plugin.py，也不附送上游图片、文本库或运行数据。功能参考与实现边界见 SOURCES.md，每包 README 给出准确用法。

## 主要指令

- F1：`/f1 下一站`、`/f1 赛历`、`/f1 积分`、`/f1 车队`、`/f1 成绩`、`/f1 排位`。默认当前赛季、UTC+8。
- 管理：`/群管`、`/群信息`、`/管理员`、`/禁言 QQ号 10m`、`/解禁 QQ号`、`/全员禁言`、`/解除全禁`、`/撤回 消息ID`、`/踢出 QQ号`。群管需要QQ实际权限，不能靠昵称自称管理员。
- 主人管理：`/管理 状态`、`/管理 插件`、`/管理 启用 插件ID`、`/管理 停用 插件ID`、`/管理 授权 QQ号`、`/管理 撤销 QQ号`。授权的是机器人群管权限，不是QQ群管理员身份。
- 提醒：`/提醒 30m 拿快递`、`/提醒 YYYY-MM-DD HH:MM 内容`、`/提醒 列表`、`/提醒 取消 编号`。只发回原会话，发送不确定时不会自动重发。
- 关键词：`/关键词 列表`、`/关键词 添加 关键词|回复`、`/关键词 包含 关键词|回复`、`/关键词 删除 编号`。仅主人能修改，默认没有任何自动回复规则。
- 记录：`/待办`、`/便签`、`/投票`、`/语录`、`/早安`、`/晚安`。
- 娱乐：`/今日运势`、`/塔罗`、`/答案之书`、`/选择`、`/硬币`、`/随机数`、`/猜词`、`/猜数字`、`/猜拳`。
- 工具：`/时间`、`/倒数`、`/字数`、`/Base64`、`/解Base64`、`/哈希`、`/URL编码`、`/URL解码`、`/游戏更新 SteamAppID`。

这些明确指令在允许的群里不需要 @，仍受机器人群和用户黑白名单约束。不会额外调用网页 GPT。娱乐结果不代表事实预测；竞猜没有赌注或真实支付。

## 安装和资源

```sh
python extensions/maibot_pack/build_pack.py --output ./dist/mai-pack-1.1.0
python -m unittest discover -s extensions/maibot_pack/tests -v
```

在插件管理逐个导入单插件 ZIP，新安装默认停用。联网插件执行超时建议18秒，其余5秒；生产部署已自动配置。统一源码 ZIP 用于开发，不是单插件安装包。

插件仅依赖 Python 标准库。核心的「插件进程数量上限」默认8，空闲进程会回收，状态保存在 `plugins/state/<插件ID>`；需要备份该目录，更新同ID插件会继续使用。15 个插件不意味着同时常驻15个进程。

F1 使用 Jolpica 公开 API，游戏新闻使用 Steam 公开 API。缓存、超时和响应大小均受限。数据是否发布、是否可达以实际服务为准，不通过模型猜测缺失赛果。
