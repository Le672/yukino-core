# 四位数AB猜谜

`/猜数字 开始`、`/猜数字 1234`、`/猜数字 状态`、`/猜数字 投降`。答案4位不重复，可能以0开头。

Yukino独立实现，功能发现参考麦麦官方插件索引及同类工具。准确来源分类见功能包SOURCES.md，不是MaiBot SDK兼容插件。Python标准库，无API密钥，不调用GPT。

需要持久化的状态只写内核分配的 `plugins/state/<插件ID>`，更新重装不丢。执行超时建议5秒，输出上限建议5000字；权限仍按QQ号和当前会话判断。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/猜数字 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
