# 麻将结构听牌与原创训练

原创 stdlib 算法与随机出题，不附带上游题库、牌面图片、网络请求、LLM 或金钱玩法。

## 牌的写法

`m` 万、`p` 筒、`s` 索；序数牌1～9。`z` 为字牌：1东、2南、3西、4北、5白、6发、7中。可写 `123m123p123s1112z`，也可在牌组之间加空格。每种最多4张；不支持0赤牌、花牌、副露或万能牌。

- `/听牌 123m123p123s1112z`：13张手牌的全部结构和牌候选。
- `/和牌 123m123p123s11122z`：14张手牌的结构判定。
- `/麻将训练 开始`：原创建型后去掉一张，确保题目至少有一个结构和牌候选。
- `/麻将训练 开始 标准`、`开始 七对`、`开始 国士`：选择出题类型。
- `/麻将训练 状态`：本人的当前题、进度，不提前给答案。
- `/麻将训练 答 2z`：提交全部候选；多种可用 `19m19p19s1234567z` 等合并记法。
- `/麻将训练 答案` 或 `投降`：结束本人题目并揭晓全部候选。
- `/麻将训练 帮助`：查看说明。

支持4面子1雀头（顺子／刻子）、七对子、国士无双。**七对子按7种不同牌各2张判断，四张同牌不算两对。** 国士仅为三门幺九和七种字牌组成的13种牌，加其中一种作对子。多种结构可以同时成立。

“手牌外理论最多N张”只扣除输入手牌持有张数，没有牌河、他家、牌山或副露信息。结果不判断役、番、点数、振听，不等同于实际规则下允许荣和，也不提供“唯一正确何切”建议。

训练要求一次提交全部候选，重复候选会报错；少报／多报会占一次尝试，但在揭晓前不泄露正确候选。答对、尝试耗尽、主动查询答案或投降后结束。当前题持久化，重启后可以继续；再次开始会替换本人已结束的上一题，不提供完整历史档案。群消息本身对群成员可见，插件不能阻止旁人手工分析公开题面，但不提供查询或修改其他用户状态的指令。

**面板参数：** `candidate_limit` 默认34（1～34），作用于 `/听牌` 展示并明确提示截断；揭晓训练答案始终完整。`max_attempts` 默认5（1～20），在新题创建时保存，不中途改变已进行题的机会。`training_style` 为混合／标准／七对／国士，影响未指定类型的新题。

结构计算不写数据库；训练仅写宿主分配的 `data_dir/mahjong.sqlite3`，按会话与用户隔离。相同群的不同用户、同一用户的不同会话都分别保存，输入参数不能指定其他用户。
