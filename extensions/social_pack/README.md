# 社交、解谜与版本查询扩展 1.0.0

本次新增10项，适用 Yukino Core 0.6.3。每项为独立 ID、ZIP 与完整用法，不把命令别名或文案条数计作插件。

| 插件 | 指令 | 范围 |
| --- | --- | --- |
| 本群漂流瓶 | `/漂流瓶` | 本群投递与捞取，作者撤回、主人管理 |
| 个人时光信 | `/时光信` | 本人私聊封存，到期本人取信 |
| 个人心情日志 | `/心情` | 本人私聊自评、备注和统计 |
| 手动睡眠时段记录 | `/睡眠` | 本人私聊手动记录起止和时长 |
| 轻量数独 | `/数独` | 4×4唯一解，文字棋盘、填数、提示 |
| 数织 | `/数织` | 5×5行列线索、标记与解谜 |
| 原创口袋远征 | `/远征` | 探索、资源、休整、背包与结局 |
| 傲娇搭话文案 | `/搭话` | 六类72句，可编辑并连续去重 |
| GitHub公开发行 | `/GitHub发行 owner/repo` | 最新正式版本、原页面与附件链接 |
| 软件包版本 | `/包版本 PyPI requests`、`/包版本 npm vue` | 官方注册表版本和必要元数据 |

每项的确切操作、配置和限制以 `plugins/<ID>/README.md` 为准。个人记录默认仅本人私聊读写；漂流瓶明确在本群公开。SQLite 是普通文件存储，不宣称端到端加密。时光信不是定时推送；睡眠记录来自手工输入，不证明真实入睡或健康状况。

搭话按指令返回，不会自行刷群。另附60句戳一戳文案及12条可选自然短语精确匹配规则，导入方法见[文案说明](../../docs/BANTER_COPY.md)。

## 构建和安装

在核心源码根目录、已安装项目依赖的 Python 3.12+ 环境运行：

```sh
python -m unittest discover -s extensions/social_pack/tests -v
python extensions/social_pack/build_pack.py --output ./dist/social-pack
```

在控制台导入生成的**单插件 ZIP**；`source.zip` 用于开发，不是面板安装包。手动安装 `s_github`、`s_package` 后，**必须先在「配置参数」将「执行超时（秒）」设为20并保存，再启用**。内核手动安装默认执行超时为2秒，包内 `recommended_settings.json` 不会由面板自动应用；网络内部预算最多15秒，保留2秒默认值会导致正常请求超时。Windows 捆绑安装会应用打包参数。默认最多8个常驻 worker，所以新增安装数不会直接变成同样多的常驻进程。

运行状态按内核提供的每插件 `data_dir` 保存；升级保留整个实例 data。插件源码和来源见[SOURCES](SOURCES.md)，不支持直接安装 MaiBot / AstrBot SDK 插件。

联网查询均有15秒网络总预算；固定 PyPI 包元数据端点允许最多8 MiB，GitHub/npm 等其他端点保持1 MiB，传输和解压后均受限。只返回必要元数据，不复制包的完整说明或发行笔记。
