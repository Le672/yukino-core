# 私人心情日志

仅本人私聊读写，群内不会公开日志。分数是用户自己选的1—5整数，不推断情绪、不作诊断。

- `/心情 记 4 | 今天修好了一个小问题`
- `/心情 记 3`：备注可以省略。
- `/心情 列表`：最近20条的时间、自评分及备注摘要。
- `/心情 统计`：当前保留记录的数量、平均、最低与最高自评分。
- `/心情 删除 1`、`/心情 清空`：仅删除自己的记录。

数据保存在本机明文数据库，管理员可以读取；请自行决定是否记录敏感信息。不是心理评估工具。

所有数据固定保存于内核分配的 `context.data_dir/social.sqlite3`；默认每人50条、总2000条、正文500字、保留365天。参数可在面板设置；到上限需先删除旧记录。执行指令时清理过期条目，时光信在到期后再保留指定天数。数据库最大64 MiB；拒绝符号链接/目录联接/硬链接状态文件。列表按最近20条展示，正文仅摘要，原文限额内保留。无外部网络、无定时推送。
