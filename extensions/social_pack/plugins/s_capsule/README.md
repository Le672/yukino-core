# 私人时光信

仅接受本人私聊中的读写；群内使用只提示私聊，不回显内容。所有时间为北京时间（UTC+8）。

- `/时光信 存 2030-01-02 09:00 | 写给未来的自己`：将示例日期改为晚于当前时间、未来365天内的分钟。
- `/时光信 列表`：只列本人最近20封的编号、到期时间和状态，不显示正文。
- `/时光信 取 1`：到期后本人可手动取信，取出后从插件数据库删除。
- `/时光信 撤销 1`：本人可随时撤销，不回显正文。

不会自动发送，到期前普通取信命令不显示正文。数据库为本机明文，不提供加密或防服务器管理员阅读的保证。QQ 聊天历史或备份中的副本不由插件删除。

所有数据固定保存于内核分配的 `context.data_dir/social.sqlite3`；默认每人50条、总2000条、正文500字、保留365天。参数可在面板设置；到上限需先删除旧记录。执行指令时清理过期条目，时光信在到期后再保留指定天数。数据库最大64 MiB；拒绝符号链接/目录联接/硬链接状态文件。列表按最近20条展示，正文仅摘要，原文限额内保留。无外部网络、无定时推送。
