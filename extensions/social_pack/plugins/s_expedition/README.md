# 雾港邮路口袋远征

你从雾港沿旧邮路出发，在第2、4、6站邮亭分别领取一份邮袋，将至少3份邮袋送到第8站灯塔即可获胜。生命归零失败。标题、场景、事件、文案及这套简化资源规则均为本插件原创，没有后室楼层、角色或故事文本。

| 指令 | 效果 |
| --- | --- |
| `/远征` | 完整帮助 |
| `/远征 开始` | 开局：生命12、体力8、口粮4、药包1 |
| `/远征 探索` | 消耗2体力前进一站，触发一个随机事件 |
| `/远征 休整` | 消耗1口粮，恢复4体力与1生命，不超过上限 |
| `/远征 使用 药包` | 消耗一个药包，恢复4生命；满血拒绝浪费 |
| `/远征 背包` | 查看本人资源、路程、邮袋与最近事件 |
| `/远征 状态` | 查看本人当前状态 |
| `/远征 结束` | 结束此局，之后可重新开始 |

事件只有顺利通行、找到口粮、碎石擦伤、海风助行和台阶跌落五类，随机抽取。邮袋固定站点保证获得，不要求抽到稀有事件；仍可能因受伤或资源耗尽失败。全部按指令推进，没有挂机收益、自动战斗、实时地图、AI角色或真实奖励。没有交易、支付或与签到金币互通。

每用户每会话独立存档，不能读取、结束或覆盖他人进度。群内输入和回复对群友可见。SQLite保存在内核分配的数据目录，worker回收、重启后继续；每份存档最多保留最近8条事件。最多2000份有效存档，30天未操作过期，仅在后续有效修改时清理本插件过期记录。拒绝链接状态文件，不访问聊天数据库。仅Python标准库，不联网、不调用模型。

“指令探索、状态与背包”的交互形式参考麦麦市场[后室探索](https://github.com/silencieuxzero/backrooms_escape)的公开功能说明；没有加载其SDK、复制源码、素材、人物、楼层或剧情。参见包内LICENSE与NOTICE。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/远征 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
