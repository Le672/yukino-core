# 傲娇搭话文案

`/搭话` 随机返回一条闲聊；`/搭话 分类` 查看全部类别；例如 `/搭话 夸夸`、`/搭话 安慰`、`/搭话 嘴硬关心`、`/搭话 随机`。

内置招呼、闲聊、无聊、夸夸、安慰、嘴硬关心六类各12条原创大陆中文文案。配置默认类别、每次1—3句、连续去重，或提供包含全部六类数组的自定义JSON。自定义每类1—100句、每句最多80字，无模板执行或模型调用。

连续去重按会话、用户和类别保存，插件重新加载后仍保留；30天未用的选择状态会清理，总状态最多10000行。不保存聊天消息，也不把不同群或用户的选择混在一起。只按指令回复，不会定时主动私聊或群发。

戳一戳60条另由内核原生通知插件使用，导入方法见仓库 `docs/BANTER_COPY.md`。
