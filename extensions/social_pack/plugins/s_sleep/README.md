# 私人睡眠时段

仅本人私聊读写，群内不公开记录。所有时间为北京时间（UTC+8）。

- `/睡眠 记 2030-01-01 23:00 | 2030-01-02 07:00`：换成实际已结束的日期，跨午夜须写两天日期。
- `/睡眠 列表`：本人最近20条起止时段及小时数。
- `/睡眠 统计`：本人保留记录数量、平均及合计时长。
- `/睡眠 删除 1`、`/睡眠 清空`：仅删除自己的记录。

结束必须晚于开始、不晚于当前时间，单条最多24小时。按手动时段相减，未去重重叠时段；不代表真实睡着时间，不作任何健康结论。

数据为本机明文，服务器管理员可读取；删除不会清理 QQ 聊天历史或备份。

所有数据固定保存于内核分配的 `context.data_dir/social.sqlite3`；默认每人50条、总2000条、正文500字、保留365天。参数可在面板设置；到上限需先删除旧记录。执行指令时清理过期条目，时光信在到期后再保留指定天数。数据库最大64 MiB；拒绝符号链接/目录联接/硬链接状态文件。列表按最近20条展示，正文仅摘要，原文限额内保留。无外部网络、无定时推送。
