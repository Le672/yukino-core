# 本群漂流瓶

仅在群聊使用，所有正文会在本群公开，默认展示不带 QQ 号码；这不是秘密信箱。不会跨群，也不会主动发消息。

- `/漂流瓶 投递 今天见到一只很像老板的猫`
- `/漂流瓶 捞一个`：随机展示一条，保留原瓶，可重复捞取。
- `/漂流瓶 我的`：本人投递的最近20条摘要。
- `/漂流瓶 撤回 1`：只能撤回自己在本群投递的编号。
- `/漂流瓶 清空`：仅配置中的机器人主人可清空当前群，不能清空其他群。

匿名仅指普通聊天展示；插件数据保留作者身份以提供撤回，机器人管理员可读取本机数据库。请勿投递隐私资料。

所有数据固定保存于内核分配的 `context.data_dir/social.sqlite3`；默认每人50条、总2000条、正文500字、保留365天。参数可在面板设置；到上限需先删除旧记录。执行指令时清理过期条目，时光信在到期后再保留指定天数。数据库最大64 MiB；拒绝符号链接/目录联接/硬链接状态文件。列表按最近20条展示，正文仅摘要，原文限额内保留。无外部网络、无定时推送。
