# 4×4唯一解数独

`/数独 开始` 创建个人棋盘。每行、每列及每个2×2宫必须恰好出现1、2、3、4，初始数字不能修改。行列均从1开始。

| 指令 | 用法 |
| --- | --- |
| `/数独` | 完整帮助 |
| `/数独 填 1 3 2` | 在第1行第3列填2，拒绝行、列或宫冲突 |
| `/数独 清除 1 3` | 清除本人填写的格子 |
| `/数独 检查` | 显示已填错格的坐标，不修改棋盘 |
| `/数独 提示` | 填入一个正确数字；已有错格须先检查、清除 |
| `/数独 撤销` | 撤销上次填、清除或提示，最多保留80步 |
| `/数独 状态` | 查看自己的棋盘和步数 |
| `/数独 结束` | 结束本局，之后可重新开始 |

完整填对16格即胜利。冲突检查不等于提前核对完整答案：不冲突的错误数字也可能使后续无解，可用“检查”定位。提示计数和总行动数不随撤销减少；已结束的局不能继续操作。

题目由程序随机变换合法终盘并挖空，逐格使用有界求解器验证唯一解；不携带第三方题库或图片。固定4×4、通常6个以上初始格，不声称支持9×9或难度评级。无需模型、网络或额外依赖。

按可信用户ID和会话ID独立存档，群里只能操作自己的局；群内输入与回复仍对群友可见。SQLite位于内核分配的插件数据目录，worker回收或重启不丢进度。最多2000份有效存档，30天未操作过期；仅在后续有效修改时清理本插件过期记录。拒绝链接状态文件，不访问核心聊天数据库。
