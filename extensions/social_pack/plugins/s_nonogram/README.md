# 5×5唯一解数织

`/数织 开始` 创建5×5个人数织。每行右侧和棋盘底部的列线索表示连续黑格长度。例如 `2,1` 表示连续两黑、至少一空、再一黑；`0` 表示整行或列为空。`?`未知，`■`涂黑，`×`标空。行列从1开始。

| 指令 | 用法 |
| --- | --- |
| `/数织` | 完整帮助 |
| `/数织 涂黑 1 3` | 涂黑第1行第3列 |
| `/数织 标空 1 3` | 明确标为空格 |
| `/数织 清除 1 3` | 恢复未知 |
| `/数织 检查` | 显示已经标错的坐标，不修改棋盘 |
| `/数织 提示` | 修正或揭晓一个格子 |
| `/数织 撤销` | 撤销上次涂黑、标空、清除或提示，最多80步 |
| `/数织 状态` | 查看自己的棋盘 |
| `/数织 结束` | 结束本局 |

全部25格明确标注且符合唯一答案时胜利，未标注的白格也需“标空”。不会因一次错标立刻失败。提示和总行动数不会因撤销减少；结束后可开新局。

只参考常见黑白数织规则，所有图案由本实现程序生成，未下载第三方题图或题库。生成最多尝试30幅，逐幅以最多8000个搜索节点、最多2解验证唯一性；必要时回退到自有的唯一解边框图案。固定5×5，不宣称更大棋盘、彩色数织或图片渲染。

无需模型、网络或额外依赖。按可信用户和会话独立保存SQLite；群里只能读取自己的存档，但群内输入和回复仍对群友可见。最多2000份有效记录，30天未操作过期，仅在后续有效修改时清理本插件过期记录。worker回收或重启不会丢进度。拒绝链接状态文件，不访问核心聊天库。

规则参考：[Conceptis黑白数织规则](https://www.conceptispuzzles.com/index.aspx?uri=puzzle/pic-a-pix/rules)。独立实现，不附送该站内容、图片或题目。参见包内LICENSE与NOTICE。


## 模型参与（Core 0.10.0）

本插件声明原生游戏AI适配器。创建/开始加“人机”或发送 `/数织 加入AI`，之后由内核按回合自动调用当前会话模型。插件管理可开启“开新局时自动邀请AI”；AI退出、AI状态、AI重试可用于本局管理。单人题目采用搭档方式，每次真人动作后最多协作一步。完整规则及隐藏信息边界见[AI游戏指南](https://github.com/Le672/yukino-core/blob/main/docs/GAME_AI.md)。本地规则引擎本身不联网；模型调用由内核管理。
