# 第三批互动扩展（12项）

适用Yukino Core 0.6.0，使用自有文字worker接口。六项通知互动另由内核提供，不计入这12个ZIP。普通新实例可按需安装；随Windows整合版提供时由启动器安装。所有玩法在原会话回复，无网络或模型依赖。

| 功能 | 指令入口 | 核心规则 |
| --- | --- | --- |
| 海龟汤主持 | `/海龟汤` | 真人主持，私聊设汤面/汤底，群问题队列与是/否/无关回答 |
| 抢答计分 | `/抢答` | 先抢先答，主持判定，答错本题不能重抢，跨题积分 |
| 轮流续写 | `/续写` | 创建开头、报名、依次续写/跳过、持久全文 |
| 群话题箱 | `/话题箱` | 自录话题、随机取出、不重复抽取、按作者删除 |
| 真心话大冒险 | `/真心冒险` | 报名抽人，本人选择任务，可无惩罚跳过，16条原创提示 |
| 谁是卧底 | `/谁是卧底` | 3—12人，私聊取词，描述投票，平票重投与胜负判定 |
| 你说我猜 | `/你说我猜` | 主持私聊取词，群中给线索、猜词和积分 |
| 队长蛇形选队 | `/选队` | 4—12人报名，两队长按A-B-B-A顺序选人 |
| 点格棋 | `/点格棋` | 双人2×2格，画边闭格得分，闭格者继续下 |
| 取石子 | `/取石子` | 双人轮流从一堆取石，拿最后一颗者胜，石堆与每步上限可设 |
| SET集合牌 | `/集合牌` | 81张四属性牌，每种属性全同或全异，校验组合与补牌 |
| 纯虚拟拍卖 | `/虚拟拍卖` | 报名、预算、递增竞价和主持落槌；无交易、付款或奖品 |

每条指令不加参数会显示完整帮助，例如`/抢答`；查看状态用`/抢答 状态`。命令均为完整前缀形式。通常先创建、加入，再由发起者开始；话题箱无需开始，SET创建即开始。群内指令无需@，仍受内核群聊开关与黑白名单限制。

秘密词只允许已加入玩家在与机器人的私聊中用房间码取出。房间码并不授予旁观者权限；不要在群里写汤底。游戏不会主动给任何人发私聊。海龟汤和你说我猜均需要真人主持，不能当作AI自动出题游戏。

发起者和机器人主人可结束本房间，普通玩家不能重置他人的进行中房间。数据按插件和群隔离，SQLite事务支持worker重启与并发写入；最多2000个房间，30天未操作的房间自动过期。结束不提供回滚按钮，源代码、数据库文件及其他插件不受此操作影响。

控制台可配置人数上限、执行/输入/输出限额；取石数量和虚拟预算可单独调整。规则参数在创建新房间时固定，避免半局改变规则。棋类始终双人。逐项使用说明在`plugins/<ID>/README.md`，构建后的每个ZIP也包含README。

功能参考、额外实现和许可见独立扩展包中的SOURCES.md；核对来源为[麦麦公开索引](https://github.com/Mai-with-u/plugin-repo/blob/main/plugin_details.json)，额外玩法与参考实现分别标注，未复制其代码或题库。构建：`python build_pack.py --output <新目录>`；测试：`python -m unittest discover -s tests -v`。输出12个独立ZIP、SHA256、整包源码和pack-manifest，不包括任何账号、聊天数据或词库下载。
