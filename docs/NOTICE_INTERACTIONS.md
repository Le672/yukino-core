# 通知与基础互动（0.6.0）

在「插件管理」搜索插件名，启用后点「配置参数」。这些功能处理NapCat实际推送的OneBot通知，不需要模型，也不要求群内再发一条@消息。

| 插件 | ID | 触发方式 | 通用新实例默认 |
| --- | --- | --- | --- |
| 戳一戳互动 | `poke` | 私聊或群聊中戳机器人 | 开启 |
| 入群欢迎 | `group_welcome` | 其他成员真实加入群聊 | 关闭 |
| 退群提示 | `group_farewell` | 其他成员主动退出或被移出 | 关闭 |
| 管理员变更提示 | `group_admin_notice` | 实际管理员任命或撤销 | 关闭 |
| 群头衔提示 | `group_title_notice` | NapCat推送群头衔变化 | 关闭 |
| 群名片变更提示 | `group_card_notice` | 实际名片前后变化 | 关闭 |

群通知可分别开启；QQ客户端或NapCat没有推送对应事件时，内核无法凭空生成通知。机器人自己发起的戳、戳其他人的事件和机器人自身退群不会触发回应。

每项配置包含回复模板、响应概率、会话冷却、用户冷却、仅指定群及是否@触发者。模板每行一条，随机选择；支持`{user}`、`{user_id}`、`{group_id}`、`{bot}`、`{action}`、`{title}`、`{old_card}`、`{new_card}`。当前`{user}`显示QQ号；花括号本身写为`{{`和`}}`。不支持模板执行代码或引用属性。

0.6.3起每项最多100条、总计6000字符。新增60条原创戳一戳文案，空实例初始化时预置；已有实例可保留自己的文案追加导入，见[文案说明](BANTER_COPY.md)。另外的72条分类搭话由普通`s_banter`插件提供，不会定时主动群发。

戳一戳另有私聊/群聊开关、附带真实表情、表情检索词和回戳。默认文字立即回复，表情和回戳默认关闭。附图使用资源库已验证图片，缺图时仍发文字；回戳仅在文字发送成功后尝试一次，权限不足或结果未知时不重试。

平台接收开关、私聊/群聊总开关、用户黑名单和群黑白名单同样生效。默认同会话5秒、同用户15秒冷却，重启后仍保留；概率设为0会完全不响应。多次相同通知会去重，避免重连后补发与循环互戳。

「事件追踪」显示通知已回应、冷却中、插件停用、目标未触发等状态。通知及其回复不会进入普通会话消息历史和模型上下文；其审计记录保存在实例数据库中。回戳失败不代表前一条文字也失败。

维护时保留整个实例`data`目录。升级核心代码即可获得这六项原生功能，不需要额外下载麦麦插件。开发者可参考`notice_plugins.py`、`transport.py`和`store.py`；第三方普通worker的接口保持不变。

事件协议依据：[NapCat事件文档](https://napneko.github.io/develop/event)、[OneBot v11通知事件](https://github.com/botuniverse/onebot-11/blob/master/event/notice.md)。
