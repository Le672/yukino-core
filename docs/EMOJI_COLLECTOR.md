# 偷表情包

“插件管理 → 偷表情包”可启停和修改参数。默认静默收集机器人已收到的表情消息，群聊无需 @；普通照片默认不自动收集，可引用后手动收藏。图片只保存在当前实例资源库，不调用模型分析，不增加日常回复的等待时间。

## 用法

- 直接发送 QQ 表情图片或商城表情：后台自动去重入库，不另发确认文字。
- 引用一条当前会话已接收的图片，发送 `/偷表情` 或 `/偷表情包`。
- 同一条消息中发送图片及 `/偷表情 开心猫`，或者引用图片发送这个命令，为收藏的表情命名；再次引用已自动收藏的表情可以补名称。
- `/表情 开心猫`：发送收藏的图片。
- `/偷表情 状态`：查看自动模式及累计收集数。
- `/偷表情 开启`、`/偷表情 关闭`：由主人控制自动模式。关闭自动模式后仍可手动收藏；面板关闭整个插件后两种方式均关闭。

已收集图片位于“资源库 → 表情资源”，可预览、编辑描述和标签、停用。群聊、私聊白名单和黑名单仍生效，停用资源不会被再次自动启用。

## 参数

| 参数 | 默认值 |
| --- | --- |
| 自动收集、群聊、私聊 | 开启 |
| 自动收集仅限表情标记图片 | 开启 |
| 每条消息上限 | 3 张 |
| 同会话自动收集间隔 | 1 秒 |
| 单张图片上限 | 5,000,000 字节 |
| 每日收集尝试上限 | 200 次，UTC+8 零点换日 |
| 累计数量上限 | 2,000 张 |
| 累计容量上限 | 256 MB，十进制 |

仅支持有效 PNG、JPEG、GIF、WebP，保留动图原始字节。自动识别依据 QQ 提供的表情类型字段，不会宣称能够理解图片内容；开启“仅表情”时，以普通图片方式发送的梗图需要手动收藏。

同一会话的原始图片必须已被本实例收到。不能用伪造引用编号读取其他会话，也不会批量补抓历史消息。仅下载 QQ 图片 CDN 的公网 HTTPS 内容，不读服务器任意路径、不跟随网络重定向。失效图片可尝试通过 OneBot `get_image` 刷新获取，仍无效时需要重发图片。

收集状态保存在实例 `plugins/state/emoji_collector/collection.json`，图片和资源描述沿用资源库的持久化目录。记录保存图片指纹和计数，不额外保存下载 URL、发送人或群号。达到上限会停止继续下载，可在面板调整；不自动删除已有图片。中断期间的容量预留保留为保守计数，状态会显示“累计收集/预留”。
