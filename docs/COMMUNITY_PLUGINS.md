# 社区功能包

根据 [QQ Agent 插件市场](https://kondius.cn/qq-agent/plugin-market/) 发现功能需求，独立实现为 Yukino Core 0.3.1+ 的 Python worker。没有复制市场下载包中缺少明确许可的上游 JavaScript、图片或数据，不宣称完整兼容上游功能。

| 插件 | 常用指令 | 本版范围 |
| --- | --- | --- |
| 签到金币 | `/签到`、`/余额`、`/金币榜`、`/转账 QQ号 金额`、`/商店`、`/背包` | 会话独立娱乐积分、签到和虚拟物品，无真实支付 |
| 好感互动 | `/好感`、`/互动` | 按指令积累，含冷却和每日上限 |
| 吃什么 | `/吃什么`、`/吃什么列表` | 可编辑菜单与排除项 |
| TRPG | `/r 3d6+2`、`/ra 60 侦查`、`/coc`、`/先攻` | 有界骰式、CoC7默认检定与基础属性 |
| 外号簿 | `/外号 设置 小鱼`、`/外号 查` | 本人登记、主人管理、权限仍按QQ号判断 |
| 天气 | `/天气 北京` | 实际解析地点、当前与未来三天文字预报 |
| Steam查价 | `/steam 620` | 商店搜索、地区价格与折扣、官方链接 |
| 热榜 | `/热榜 b站` | 按指令查询公开榜单 |
| 网易云检索 | `/搜歌 歌名` | 歌曲ID、歌手、官方页，不下载付费歌曲 |
| MC状态 | `/mc mc.hypixel.net` | Java服务器在线状态，不提供RCON |
| B站查询 | `/B站搜索 关键词`、`/直播 房间号` | 公开搜索与当前直播状态，不定时推送 |

这些明确指令可在允许的群聊中无需 @，仍遵守群与用户黑白名单。命中插件后不调用语言模型；联网源失败会返回错误，不把缺失结果编造成回复。

在控制台的插件管理中导入单插件 ZIP；默认停用，审核自己的包后启用。联网插件执行超时建议 18 秒，本地插件 5 秒。数据源可能因所在网络、源站限流或接口调整暂不可用，安装成功和协议测试不等于所有源在每个地区都可用。

数据保存在实例 `plugins/state/<插件ID>`。更新或重装同 ID 仍复用该目录；备份实例时保留目录和数据库。移除插件不会清除此目录。

功能包作为额外产物发布，核心通用源码 ZIP 不携带个人数据、下载的上游插件或既有私有集成。开发源码位于 `extensions/community_pack`，包含逐项说明、参考来源、测试与打包工具。具体命令参数以每包 README 和配置界面为准。
