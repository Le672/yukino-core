# 63项实用扩展

适用 Yukino Core 0.5.0，扩展包版本1.0.0。开发与数据工具、生活协作、文字游戏各21个，共63个独立插件ID和ZIP。原有社区及麦麦功能参考包可继续使用；内核上限为128个外部插件，进程池默认8，不会同时常驻全部插件。

## 安装与管理

开发源码位于 `extensions/expansion_pack`。使用该目录README的构建、测试与真实worker验收命令，构建生成63个单插件ZIP、统一源码ZIP、SHA-256及清单。统一源码ZIP不是可直接上传的插件安装包。

控制台进入「插件管理」，输入名称、ID、功能或命令搜索；可以筛选已启用、已停用、运行异常、原生功能和进程插件。每张卡片显示注册指令，点击「配置参数」调整适用字段与执行限制。新导入的插件默认关闭，需按需要启用；完整包安装需要0.5.0内核。

明确指令在允许的群里无需@，但仍受用户和群访问限制约束。以下指令均直接调用worker，不额外调用模型。输入数值、JSON、竖线分隔和编号的完整语法以各插件README及帮助回复为准。

## 数据、权限与能力

- 个人记录按会话与用户划分，群协作按会话和创建者权限划分。状态写入固定的 `plugins/state/<插件ID>`；更新代码、进程回收和重装同ID源码不会自动清空数据。
- 用户隔离限制的是记录查询权限；输入与回复仍在原会话中，群友能够看到群内消息。游戏状态31天未操作会清理，每个游戏最多保留5000桌，不影响聊天历史或其他插件记录。
- 生活协作的归档保留原数据。共享项目的关闭、推进、修改等敏感操作需要创建者或机器人主人，群员不能任意接管别人的项目。
- 多人棋盘需要加入并按回合行动；单人游戏分别记录进度。游戏是文字消息交互，无赌注、现金或支付。
- 番茄钟、复习、纪念日、工时支持记录与查询，不负责主动推送；需要到点发QQ消息时使用内核原有的 `/提醒`。
- 所有新增功能以Python标准库为基础，核心使用不需要新的账号或付费API。工具中的查询是对输入数据或有限内置参考的处理，没有声称实时联网取得外部站点内容。
- 普通worker仍只返回文字。媒体、群管、模型调用等宿主能力没有因此扩展为公共SDK，边界见 [插件编写指南](PLUGIN_AUTHORING.md)。

发布、备份时分开保存源码包和实例状态。不要把SQLite、运行凭据或私人输入打进公共插件ZIP。新实现的来源边界见扩展包SOURCES.md，内核既有素材与依赖的审查状态继续以项目发行说明为准。
