# 联网查询与主动搭话

Yukino Core 0.8.0、扩展包1.2.0。

## 真实联网查询

| 功能 | 用法 | 数据源与结果 |
| --- | --- | --- |
| IP归属 | `/IP信息 8.8.8.8`、`/IP查询 1.1.1.1` | 实际国家/地区、城市、ISP/组织、ASN、时区；ipwho.is，失败尝试ipapi.co |
| 服务器出口 | `/IP信息` | 明确标注为机器人服务器出口IP，不能推断发消息者的IP |
| DNS | `/DNS example.com MX`、`/域名查询 example.com` | Google Public DNS真实记录、类型、TTL；支持A、AAAA、CNAME、MX、TXT、NS、SOA、CAA |
| 网站状态 | `/网站状态 https://example.com/`、`/HTTP状态 https://example.com/` | 实际HEAD状态、最终地址、类型、响应长度和服务器头、从服务器出发的检测耗时 |
| 链接信息 | `/链接信息 https://example.com/` | 链接结构与实际网站状态；`/清理链接`仍是本地转换 |

IP/CIDR本地分析保留。私网、回环、保留和非全局地址只在本地分析，不发给外部归属服务。归属是数据库估计；没有风险、VPN或黑名单数据时不据此编造结论。网站检测只访问公开HTTPS，逐跳校验DNS/IP/TLS，限制时间、响应与跳转次数，不访问内网。站点拒绝HEAD时如实说明，可另用`/网页正文`。

IP、链接、HTTP插件各自有“允许联网查询”、网络超时、成功结果缓存等设置。缓存默认600秒；单个数据源默认8秒，含备用源的插件总时限30秒。免费数据源限额和可用性由提供方控制。

其余已接真实公开数据的15个扩展：天气、Steam商店、音乐、B站搜索/直播、热榜、MC状态、F1、游戏更新、RSS、Bangumi番剧、缩写释义、网页正文、Bing壁纸、GitHub发行、PyPI/npm版本。它们的查询会实际联网；原站返回下架、限流、无记录或不可达时返回真实状态，不交给模型猜测。

MC的“离线/不可达”是第三方探测结果，不等于插件没有联网。`/GitHub发行 owner/repo`查询Release，无正式Release的仓库会明确显示没有记录。热榜仍只输出编号和标题。

B站搜索和热榜可使用可选的本地会话代理。由部署者设置环境变量`YUKINO_BILIBILI_BROKER_SETTINGS`，指向服务端私有JSON（`url`和`token`）。仅允许本机/命名视频侧边服务的17831端口；代理只接受固定的搜索/热门操作，不接收任意URL。该私人集成不包含在公开包里；未配置时仍查询公开接口。站点会话只留在部署者服务器上，不返回给QQ、模型或公开发行包。

## 主动参与群聊

控制台“对话策略 → 主动搭话”可直接编辑以下设置，保存后影响新消息：

- 开关与群白名单：主动参与群聊、主动搭话群白名单。还要满足原有群聊开关、群/用户黑白名单与机器人过滤。
- 搭话概率、最少文字数：普通群消息无需@，按概率进入同一模型队列。指令、自动解析链接、对其他人的@和引用，不额外插入模型闲聊。
- 同群间隔、每群/全局小时上限：预算持久保存在SQLite，重启不会清空。模型失败或决定不说话也消耗本次主动预算，防止反复请求。
- 上下文条数、回复长度：参考同群最近消息与原人格，默认简短一两句。没有适合接的话时模型可返回内部`[[silent]]`，内核不会把它发到群里。
- 安静后接续话题：仅对本次运行收到过近期真实人类消息的群生效；每轮人类活动后最多接续一次。机器人自己说话不会让群无限保持活跃，重启不会回放旧群消息。
- 免打扰开始/结束小时与UTC时区；开始和结束相同表示关闭免打扰。

主动搭话不会在私聊里主动找陌生人。发送前检查QQ禁言字段；断线、禁言、关闭接收、模型不健康、队列忙、重置或关闭开关时跳过。直接@、名字唤醒、回复机器人、插件指令等原有触发继续可用，不受主动搭话概率限制。

全新公开安装默认关闭主动搭话。部署者应在自己的群范围启用并设置合适频率。状态接口的`proactive`包含候选参与、主动接续、实际发送、跳过、预算拦截等运行计数。
