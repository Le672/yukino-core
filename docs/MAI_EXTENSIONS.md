# 麦麦功能参考扩展

0.4.0 核心增加群管与管理员、提醒、关键词自动回复三个原生插件，另外发布15个独立 worker，见可选源码 `extensions/maibot_pack` 的 README。它们采用Yukino插件接口，不是麦麦插件的直接兼容运行。

## 群管与管理员

群管插件可查询当前群信息和成员公开资料，禁言、解禁、全员禁言、撤回、踢人、修改群名片和群名称。命令只针对当前消息所在群；不支持私聊指定任意群执行动作。每次操作通过OneBot查询真实群角色，不信任消息里的昵称、身份自称或模型判断。机器人仍需QQ实际管理权限，且不会对机器人自身、机器人主人或群内高权限成员执行禁言/踢出。

机器人主人可用 `/管理 授权 QQ号` 添加群管操作者，也可在插件配置的「机器人授权群管QQ」中编辑。默认允许QQ实际群主/管理员管理本群，普通群员不能管理。额外群管不能再次授权他人，机器人主人的名单仍在平台连接中管理。

QQ管理员身份变更默认关闭。明确开启后仍要求机器人实际是群主，且由已配置的机器人主人操作。群管动作只尝试一次，返回不确定时需要先核对QQ里的真实结果，不自动重放。

## 提醒

`/提醒 30m 拿快递`；支持s/m/h/d和秒/分钟/小时/天。绝对时间用 `/提醒 YYYY-MM-DD HH:MM 内容`，默认UTC+8。至少5秒后，默认最长365天、每用户每会话10个待处理任务。用 `/提醒 列表` 查看、`/提醒 取消 编号` 取消本人在本会话的任务。

任务写入独立SQLite，重启保留。只发回发起任务的原QQ会话，不接受指定陌生目标。发送前仍检查接收开关、会话与用户访问限制；受限制会暂停，超过补发宽限期会过期。每个任务发送前先持久化认领；断线、服务中断或发送结果不确定时不会自动重发。记录保留以便查询。服务关闭期间不会发送，恢复后只处理宽限期内任务。

## 关键词

默认规则为空，由主人在面板编辑JSON，或用 `/关键词 添加 关键词|回复`、`/关键词 包含 关键词|回复`、`/关键词 删除 编号`。精确和包含匹配均是普通字符串，不执行正则或代码。群聊命中显式规则不需要@，但仍先检查群/用户访问限制。命中后的冷却不会回落到模型重复回复。

## 进程与状态

「对话策略 → 插件进程数量上限」默认8，空闲进程按最近使用时间回收，忙碌进程不因新请求被强制杀死；满载时明确返回稍后重试。降低上限后在后续调用中回收空闲进程，已执行中的任务继续处理。状态目录按插件ID固定，回收进程不会丢失签到、游戏或其他数据。

默认通用核心源码包包含三个原生插件。15个worker以独立ZIP和源码包另外发布，不附送实例账号、凭据、记录或第三方素材。
