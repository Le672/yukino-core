## 未确认项与公开发布前要求

1. **完整历史来源比对未完成。** 现有目录结构、程序入口和运行状态支持它是独立运行的内核，但不能替代逐文件来源审查。尚未对全部历史提交与 MaiBot/AstrBot 等上游逐段比对，不应宣传“所有代码完全原创”或“绝无授权纠纷”。发现实际复制代码后，应记录源文件、提交、作者和适用许可证，再决定保留、替换或按上游条件分发。
2. **传递依赖与镜像不是本次全部审查对象。** aiohttp 的依赖、Pillow 的编解码器、加密依赖、Python 和 Debian 基础镜像包需要针对最终锁定的版本再生成软件物料清单。当前源码包不捆绑这些 wheel 或二进制。不能把当前报告当作离线安装包或镜像的完整合规凭据。
3. **FFmpeg 取决于实际构建选项。** 可选视频镜像使用系统包，其构建可能启用 GPL 组件；发行该镜像前查看 `ffmpeg -buildconf`、发行包版权清单及源码提供义务。[FFmpeg 官方说明](https://ffmpeg.org/legal.html)
4. **可选服务尚未通用化。** 开发仓库的姬漫/视频部署含私人账号、站点地址和现有镜像依赖，默认发行包排除整个 `integrations` 目录。将其另行发布前应移除这些绑定，核对 API 服务授权和稳定性，并分别提供依赖、许可和部署示例。
5. **用户导入素材授权未知。** 资源来源清单或素材仓库上的开源代码许可证不必然覆盖每张梗图、人物、漫画、视频或商标。它们未进入默认发行包；不能直接把 VPS 资源库作为公共附件上传。
6. **其他依赖按实际采用审查。** 当前核心/可选组件 requirements 未直接使用 jmcomic 或 pikepdf，因此不把它们写成已捆绑依赖。若发行后端、复制实现或新增安装项，应补充 [JMComic 官方 LICENSE](https://github.com/hect0x7/JMComic-Crawler-Python/blob/master/LICENSE) 与 [pikepdf 官方 LICENSE](https://github.com/pikepdf/pikepdf/blob/main/LICENSE.txt) 及其传递依赖。

默认源码包可以构建并本地验证；公开上传、镜像分发与合规声明仍应由维护者根据上述证据和未确认项作出决定。构建 manifest 将状态明确保留为 `review_required_see_docs_LICENSE_REVIEW`。
