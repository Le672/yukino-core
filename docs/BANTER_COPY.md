# 中文戳一戳与搭话文案

资源文件：[resources/banter.zh-CN.json](../resources/banter.zh-CN.json)。文案为本项目原创，采用自然、俏皮、轻度毒舌和嘴硬关心的口吻，适用于中国大陆中文聊天。每条都是单行短句，最长不超过 80 字。

共 **132 条**，各列表内部及全部列表之间均不重复：

| 分类 | 数量 | 用途 |
| --- | ---: | --- |
| 戳一戳 `poke` | 60 | 收到私聊或群聊中的真实戳一戳事件后，随机选用 |
| 招呼 | 12 | 打招呼、开始一段对话 |
| 闲聊 | 12 | 提出容易接话的小问题 |
| 无聊 | 12 | 轻松小活动与话题，不要求用户完成任务 |
| 夸夸 | 12 | 按需选用的鼓励文案；不是对未知事实的判断 |
| 安慰 | 12 | 接住情绪，不诊断、不强迫积极 |
| 嘴硬关心 | 12 | 提醒喝水、吃饭、休息和放松 |

## 导入与使用

这是结构化文案资源，**不是插件安装 ZIP**，不要把 JSON 上传到「从本地 ZIP 安装」。将整个文件保留在仓库或发行包的 `resources` 目录，供内核或文案插件读取。

### 用维护脚本导入

先停止使用该 `data` 目录的核心，并备份整个实例 `data` 目录。**Linux/Docker 部署必须先停止对应服务或容器**；Windows 使用 `Stop.cmd` 正常停止。关闭网页不会停止服务。导入期间也不要在面板、编辑器或其他程序中保存该实例配置。在仓库根目录使用运行该实例的 Python 执行：

```sh
# 先预览，检查将新增的戳一戳模板与搭话规则。
python scripts/import_banter.py --data ./data --include-keywords --dry-run

# 确认预览内容后执行导入，再按平时方式启动核心。
python scripts/import_banter.py --data ./data --include-keywords
```

将 `./data` 换成实际实例的数据目录。**脚本不能可靠检测所有运行中的实例，也没有与核心共用的进程锁，必须由维护者先停机。** `runtime.json` 只是 Windows 启动器提供的额外保护，存在时会拒绝导入；Linux/Docker 通常没有该标记，缺少它不表示服务已停止。在运行中的实例上导入，后续面板保存可能用进程中的旧配置覆盖导入结果。

脚本会在替换前检查配置是否已被其他程序改写，发现变化时拒绝覆盖；这不能消除所有并发写入的时间窗口，因此不能代替停机。执行导入时会自动备份配置，但这不能代替包括数据库、插件状态等内容的完整 `data` 备份。

默认保留现有戳一戳模板，追加本资源中的新句子并去重。可选参数 `--include-keywords` 还会添加**精确匹配**的自然搭话短语规则，保留同名的现有规则；只想补充戳一戳时去掉此参数。`--dry-run` 仅预览，不写入配置。

若合并结果会超出 **100 条戳一戳模板、6,000 字符或 50 条关键词规则**的限制，脚本会整体拒绝导入并报告原因，不截断文案，也不只写入一部分。请先整理已有配置，再重新预览和导入。

### 在面板手工更换

在控制台「插件管理 → 戳一戳互动 → 配置参数」找到「回复模板」。将 `poke` 数组中的句子按**一行一句**粘贴后保存；不需要 JSON 的方括号、双引号或逗号。保存会替换现有模板，想保留自己的句子请先复制备份，再合并去重。

本次更新将戳一戳模板上限扩展到 **100 条、总计 6,000 字符**，可以保存资源中的全部 60 条。旧版 0.6.2 最多接受 30 条，未升级时请从中选不超过 30 条使用。概率、会话冷却、用户冷却、群范围和私聊／群聊开关仍分别控制实际回应，增加模板不会绕过这些设置。

### 使用搭话文案插件

搭话句子位于 `smalltalk` 对象下，由普通外部插件「搭话文案」（ID：`s_banter`）按分类读取。在控制台安装并启用该插件后可以发送：

```text
/搭话
/搭话 分类
/搭话 招呼
/搭话 夸夸
/搭话 嘴硬关心
```

`/搭话` 默认选择「闲聊」，`/搭话 分类` 列出全部六类；`/搭话 类别` 从该类随机选一句。不需要调用模型。搭话句子不是戳一戳模板，不应混到 `poke` 数组中。

**这些文案用于触发后的回复，不是定时主动私聊或群发任务。** 导入文案不会自行向联系人或群聊发送消息。

## 占位符与编辑

`poke` 可使用内核已有的 `{bot}`、`{user}` 占位符。当前 `{user}` 会显示触发者的 QQ 号，因此本资源多数句子不带它，减少每句都点名的生硬感；`{bot}` 由实例的机器人显示名替换。花括号本身写作 `{{` 和 `}}`。本资源中的搭话句子没有占位符。

文件格式为：

```json
{
  "format": 1,
  "locale": "zh-CN",
  "poke": ["戳什么戳，我又没掉线。"],
  "smalltalk": {
    "招呼": ["在呢，把你想说的慢慢打出来。"],
    "闲聊": [],
    "无聊": [],
    "夸夸": [],
    "安慰": [],
    "嘴硬关心": []
  }
}
```

上方仅演示字段结构，完整句子以资源文件为准。编辑时保持 UTF-8 编码、合法 JSON 和单行短句；每个分类保留独立数组。新增句子应避免辱骂歧视、暧昧依赖、威胁、身份冒充或编造亲身经历，也不应把不熟悉的梗生硬堆在一句话里。

不建议给所有场景都套同一句“哼”。可以交替用简短回应、轻松吐槽、具体提问和适度关心；对难过或求助的用户优先用安慰分类，不拿脆弱处境开玩笑。
