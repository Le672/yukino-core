# Yukino Core 0.6.2 冻结发行附件

此分支保存已测试和校验的公开发行包，以及将它们上传到 GitHub Release 的受限工作流。核心源码和使用说明在 [main 分支](https://github.com/Le672/yukino-core/tree/main)，发行 tag 对应源码提交，不指向此附件分支。

工作流只在本仓库的此发行分支运行，先核对源码提交的跨平台检查，再逐个校验并上传七项附件；已有同名但内容不同的附件会导致失败，不会静默替换。全部远端哈希一致后才发布草稿。认证使用 GitHub 提供的临时工作流令牌，没有存放个人凭据。

公开附件没有运行实例数据。Windows 内含 Python 与第三方依赖，许可证和锁定清单位于便携包内；源码与各插件保留各自的许可声明。
